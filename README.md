## 🧠 About the Project

**GTAVI React + Vite Application** is a fast, modular, and modern frontend web app built with **React** and **Vite**.  
It demonstrates clean architecture, blazing-fast development with HMR, and code linting with **ESLint** for better quality and maintainability.

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rohitlakha/GTAVI-React-Vite-App/.git
   cd GTAVI-React-Vite-App

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open in browser** → http://localhost:5173
